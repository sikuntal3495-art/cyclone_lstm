🌪️ **One of My Best Projects: Cyclone Prediction Using LSTM**

I’m excited to share one of my most interesting projects: **Cyclone Prediction Using LSTM (Long Short-Term Memory)**.

In this project, I explored time-series forecasting using deep learning to predict future cyclone parameters such as latitude, longitude, wind speed, and pressure based on historical observations.

📊 **Model Performance:** Achieved approximately 97% accuracy in my initial experimental results.

⚠️ **Important Note:** This result is based on a very small dataset and limited observations. Therefore, the reported performance should not be considered reliable real-world cyclone prediction accuracy. More historical cyclone data, proper validation, and extensive testing are required to evaluate the model's actual predictive capability.

This project helped me gain practical experience with:
- LSTM-based time-series forecasting
- Data preprocessing and MinMaxScaler
- Sequence creation and prediction
- Deep learning model evaluation
- Visualizing actual vs predicted cyclone trajectories
